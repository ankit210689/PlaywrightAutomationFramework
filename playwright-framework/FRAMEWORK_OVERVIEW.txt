Playwright Framework Overview

This document describes the structure, responsibilities, and run instructions for the Playwright pytest framework located at:

PlaywrightAutomationFramework/playwright-framework

1) High-level summary
- Purpose: Automate a checkout flow on https://www.saucedemo.com using pytest + Playwright.
- Design: Page Object Model in `pages/`, tests in `tests/`, test data in `data/`, helpers in `utils/`, and runtime output in `reports/`.

2) Project layout
- playwright-framework/
  - tests/
    - test_checkout.py      # single pytest-style test that orchestrates the checkout flow
    - conftest.py          # pytest fixtures for Playwright (browser, page, session)
  - pages/
    - login_page.py        # LoginPage class: fills #user-name, #password, clicks #login-button
    - products_page.py     # ProductsPage class: list items, add_items_above(threshold), go_to_cart()
    - cart_page.py         # CartPage class: get_cart_items(), checkout()
    - checkout_page.py     # CheckoutPage class: fill_info(), continue_to_overview(), finish(), get_order_summary()
  - data/
    - checkout_data.json   # test input data (first_name, last_name, postal_code)
  - utils/
    - helpers.py           # parse_price(), save_order_details(path, items, total)
  - reports/
    - order_details.txt    # generated by the test at runtime
  - requirements.txt       # Python dependencies (pytest, playwright, etc.)
  - pytest.ini             # pytest config
  - README.md              # setup & run instructions
  - FRAMEWORK_OVERVIEW.txt # this file

3) Responsibilities: short descriptions
- `tests/test_checkout.py`:
  - Orchestrates the end-to-end flow:
    1. Navigate to https://www.saucedemo.com
    2. Login as `standard_user` / `secret_sauce`
    3. Add all products priced > $10 to the cart
    4. Proceed to checkout, supply data from `data/checkout_data.json`
    5. On the overview page, collect item names and total, write results to `reports/order_details.txt`
    6. Finish purchase
  - Implementation notes:
    - The test ensures the project root is added to `sys.path` so `pages.*` and `utils.*` imports resolve when running pytest. Example:
      sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1]))
    - The test collects the overview summary (total) before calling `finish()` because the final confirmation page does not include `.summary_total_label`.

- `pages/` (Page Object Model):
  - Each page class encapsulates selectors and actions to reduce duplication and improve readability.
  - Example (conceptual):
    - ProductsPage.add_items_above(10.0) will iterate `.inventory_item` rows, parse text from `.inventory_item_price` and click the product-specific add button when price > 10.0.

- `utils/helpers.py`:
  - parse_price(text) -> float: strips `$` and converts to float.
  - save_order_details(path, items, total): writes item lines and final total to a file.

4) Key code excerpts (short)
- Add project root to sys.path (in test module):
  import sys, pathlib
  sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1]))

- Collect overview summary before finish():
  checkout.continue_to_overview()
  summary = checkout.get_order_summary()  # reads .summary_total_label here
  checkout.finish()

5) How to run locally (zsh)
- From the framework folder:

```bash
cd /Users/ankit/PycharmProjects/GitHubCopilot/PlaywrightAutomationFramework/playwright-framework
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
pytest tests/test_checkout.py -vv
```

- After successful run, view the generated report:

```bash
cat reports/order_details.txt
```

6) Where outputs appear
- Console: pytest output (e.g., `1 passed`)
- File: `reports/order_details.txt` contains the purchased item names and final total.

7) Common issues & notes
- Do NOT run the test file directly (e.g., `./tests/test_checkout.py`) from zsh; use `pytest` or `python`. Direct execution can cause `zsh: permission denied` or wrong interpreter behavior.
- If imports fail for `pages`/`utils`, ensure you run pytest from the `playwright-framework` root or that the test module adds the project root to `sys.path`.
- If a selector changes on the site (class names or IDs), update the corresponding `pages/*` class method.
